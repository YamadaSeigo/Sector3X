\subsubsection*{template$<$class T$>$\newline
class One\+Or\+More$<$ T $>$}
1個以上の要素を格納するコンテナクラス 

内部的には、要素が0個のときはstd\+::monostate、1個のときは\+T、複数のときはstd\+::vector$<$\+T$>$を保持する。要素の追加はadd()やemplace()で行い、取得はget()やoperator\mbox{[}\mbox{]}で行う。サイズや空判定も提供する。
