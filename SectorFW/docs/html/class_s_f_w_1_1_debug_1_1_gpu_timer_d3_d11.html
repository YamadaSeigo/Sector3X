詳解

Direct3D11用のGPUタイマー

  • タイムスタンプクエリをリングバッファで管理
  • 未解決（GPU がまだ終わっていない）クエリは再利用しない → QUERY_BEGIN_ABANDONING_PREVIOUS_RESULTS / QUERY_END_ABANDONING_PREVIOUS_RESULTS を回避
  • 空きスロットがない場合、そのフレームの計測はスキップする
